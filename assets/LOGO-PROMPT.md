# ClipHawk logo artwork

The master artwork is `cliphawk-logo.png`, a 1254 × 1254 RGBA PNG with a transparent
background. It was generated with the built-in `image_gen` tool in transparent
background mode. The same artwork supplies the README logo and extension icon sizes.

## Generation prompt

Use case: logo-brand. Asset type: production logo mark for the ClipHawk video-grabber browser extension, also to appear in its GitHub README. Create a single bold minimalist hawk head/profile facing right, fused elegantly with a right-facing video play triangle through clean negative space. It must read as one coherent memorable emblem, not a bird next to a separate button. Style: sophisticated flat vector-like geometry, precise crisp edges, confident angular silhouette, sharp but approachable, contemporary software brand. Palette: warm amber #ffae54 and vivid orange #ff8a00 with limited deep charcoal #111416 detail; use few solid colors, strong contrast. Composition: one centered mark in a square canvas, filling roughly 85% of the square with balanced padding; designed to remain recognizable at tiny browser toolbar sizes. Background: genuinely transparent alpha. No words, no letters, no captions, no border, no enclosing app tile, no gradients, no shadows, no 3D, no mockup, no texture, no extra symbols or decorative lines. Use broad shapes and minimal detail; incorporate a small purposeful eye and a clear beak without thin lines.

## Export notes

Keep the PNG alpha channel when creating smaller icons. Icon resizing is a
deterministic export from this master; do not regenerate each size independently.
